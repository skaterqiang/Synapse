# 发动机缸体加工工艺规程（产品号 EB-4G15）

## 一、背景

某汽车零部件企业生产四缸发动机缸体（EngineBlock），把「工艺路线 → 工序 → 设备/刀具/参数 → 质量检验 → 批记录」全流程数据挂到 IAO（信息工件本体）+ BFO 顶层本体上，实现工艺规程指导生产执行、参数实时采集、质量追溯与批记录归档。

## 二、信息工件（IAO）视角

现场的纸质/电子记录都是信息内容实体，承载于物理载体，并**是关于（is_about）**某个加工过程或物理对象的：

| 信息工件 | IAO 归类 | 关于（is_about） |
|---|---|---|
| 工艺规程 MP-EB-4G15 | 指令性信息实体 | 缸体全部加工活动 |
| NC 加工程序 | 指令性信息实体 | 数控加工活动 |
| 参数采集记录 / 质检报告 | 测量数据项 | 对应工序的加工过程 |
| 批生产记录 | 文档 | 整个批次的生产过程 |

## 四、缸体结构与设备

发动机缸体（EB-4G15）是组合个体，由缸体本体（铸件）、4 个缸孔、主轴承座 ×5、油道、水套组成；缸体又是「4G15 发动机总成」的组成部分，发动机总成是「整车」的组成部分。

- 卧式加工中心 MC-21 连接到排屑器 CONV-21 与冷却液站 COOL-21。
- 缸孔镗床 MC-24 连接到在线测量头 Probe-24。
- 三坐标测量机 CMM-02 位于恒温计量间（20±1 ℃）。

## 五、约束

1. 工艺规程（信息工件）必须表征于对应的加工活动，不得孤立存在。
2. 参数采集记录的数值必须有计量单位与采集时间戳。
3. 物理对象（设备、工件）与活动（工序）不相交。
4. 工序顺序不得成环；每道工序必须关联至少一台设备。
