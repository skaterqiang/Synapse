# 感冒临床诊疗路径（呼吸内科门诊）

## 一、目的

规范普通感冒与流行性感冒的门诊诊疗流程，把「症状 → 检查 → 诊断 → 治疗」闭环知识结构化，供临床决策支持系统（CDSS）推理。

## 二、顶层本体对齐

| 临床概念 | BFO/OGMS 归类 | 说明 |
|---|---|---|
| 患者、病毒 | 物质实体（material_entity） | 独立持续体；患者属人体（organism） |
| 发热、咽痛、咳嗽 | 性质（quality） | 依附于患者身体的可观察属性，内在于（inheres_in）患者 |
| 感染倾向 / 病理状态 | 倾向（disposition） | 患者身体的病理倾向 |
| 患者角色 | 角色（role） | 依情境获得，由患者承载（bearer_of） |
| 体格检查、血常规检验 | 过程（process） | 有始有终的诊疗活动，发生于（occurs_in）门诊诊室 |
| 诊断结论 | 信息内容实体（generically_dependent_continuant） | 记载于病历文档 |
| 门诊就诊 | 过程（process） | 由多个子过程组成，有参与者（has_participant） |

## 三、症状-疾病知识

**普通感冒**：鼻塞、流涕、咽痛、咳嗽、低热（37.3–38.0 ℃）；病原为鼻病毒、冠状病毒；自限性 5–7 天；对症治疗（解热镇痛、缓解鼻塞、止咳），不需抗生素。

**流行性感冒**：高热（≥ 38.5 ℃）、全身肌肉酸痛、显著乏力、咽痛、干咳；病原为甲型/乙型流感病毒；检查为流感抗原快速检测、咽拭子核酸；发病 48 小时内用奥司他韦抗病毒 + 对症退热。

**急性扁桃体炎**：咽痛剧烈、吞咽困难、扁桃体红肿化脓、发热；病原为 A 组β溶血性链球菌；检查为血常规（白细胞与中性粒细胞升高）、C 反应蛋白；用青霉素类或头孢类。

## 四、检查项目

| 检查名称 | 类型 | 检出指标 | 用于鉴别 |
|---|---|---|---|
| 体温测量 | 体格检查 | 体温值 | 区分低热与高热 |
| 咽部视诊 | 体格检查 | 咽部充血、扁桃体化脓 | 区分感冒与扁桃体炎 |
| 血常规 | 检验 | 白细胞、中性/淋巴细胞比例 | 区分病毒性与细菌性感染 |
| C 反应蛋白 | 检验 | CRP 浓度 | 细菌感染时升高 |
| 流感抗原快速检测 | 检验 | 流感病毒抗原 | 确诊流行性感冒 |

## 五、诊疗路径

1. 患者以主诉症状就诊，挂号建立门诊就诊过程。
2. 医师进行体格检查（体温测量、咽部视诊），过程发生于诊室，患者是参与者。
3. 按症状开具检验：疑似细菌感染开血常规 + CRP；疑似流感开流感抗原检测。
4. 检查结果产生信息内容实体（检验报告），记载于病历。
5. 医师综合症状与检查结果给出诊断结论。
6. 按诊断启动治疗过程：感冒对症治疗、流感抗病毒治疗、扁桃体炎抗生素治疗。
7. 治疗过程实现（realizes）药物的治疗功能；患者承载「服药者」角色。

## 六、一致性约束

- 性质必须内在于某个独立持续体，不得悬空。
- 持续体与发生体不相交：患者不能同时是一个检查过程。
- 检验过程的参与者必须是持续体；过程不能参与另一个过程。
- 同一患者不能同时承载两个互斥的诊断角色。
