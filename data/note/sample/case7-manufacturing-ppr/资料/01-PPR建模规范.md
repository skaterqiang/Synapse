# 产品-工艺-资源（PPR）建模规范

## 一、背景

某离散制造企业（汽车零部件）按 ISA-95 / ISO 15926 风格构建制造知识图谱本体层，核心骨架是「产品(Product)-工艺(Process)-资源(Resource)」PPR 三角：**用什么资源，按什么工艺，造什么产品**。本体文件由工艺工程师维护，发布后供 MES / ERP / PLM 消费。

## 二、三类核心对象

- **产品（Product）**：可交付的实物，如变速箱壳体、发动机缸体。产品由零部件组成（BOM 结构，组成关系可传递）。
- **工艺（Process / Activity）**：有目的的加工活动，如粗铣、精镗、钻孔、清洗、检验。工艺之间存在先后顺序（时序偏序，可传递）。
- **资源（Resource）**：完成工艺所需的物理对象，如加工中心、数控车床、刀具、夹具、量具。

## 三、时空观约定

按 ISO 15926 的 4D 观点：

- 产品与资源是**物理对象（physical_object）**；由部件组合而成的装配体是**组合个体（arranged_individual）**。
- 工艺是**活动（activity）**；开工、完工、报废等时间点是**事件（event）**；加工周期、班次是**时间段（period_in_time）**。
- 产品型号、工艺规程编号、资源类别是**类（class）**；具体的某台设备、某件在制品是个体，个体**归类于**其所属类。
- 工艺规程文档、加工程序（NC 代码）、检验记录是**信息表征**，它们**表征于**对应的活动或物理对象。

## 四、关系约定

| 关系 | 含义 | 特性 |
|---|---|---|
| composedOf | 产品由零部件组成 / 设备由部件组成 | 传递 |
| involvedIn | 资源参与某道工艺活动 | — |
| startsBefore / endsBefore | 工艺之间的先后顺序 | 传递（时序偏序） |
| classifiedBy | 个体设备/产品归类于型号类 | 定义域=可能个体，值域=个体的类 |
| hasSuperclass | 型号类的父类 | 定义域与值域都必须是类 |
| connectedTo | 设备之间的物理连接（如机床连接到排屑器） | 对称 |
| containedIn | 在制品被包含于某工位/料架 | 传递 |
| representsIn | 工艺规程/NC 程序表征于某活动 | — |
| existsAt | 事件或状态存在于某时间段 | — |

## 五、约束

1. 物理对象与活动不相交：一台设备不能同时是一道工序。
2. 可能个体与抽象对象不相交：型号类是抽象对象，不能与物理对象建立 connectedTo 这类物理连接。
3. 工艺顺序不得成环。
4. 每道工艺必须至少关联一种资源，否则无法排产。
