# 家谱应用亲属关系推导规则

## 一、目的

家谱/社交应用只要求用户录入最基础的直系关系（父母、兄弟、夫妻），其余亲属称谓由系统按规则自动推导，减少录入负担并保证称谓一致。

## 二、基础关系

系统中登记的基础关系包括：父亲（hasFather）、母亲（hasMother）、兄弟（hasBrother）、姐妹（hasSister）、丈夫/妻子（spouse）。每位家庭成员都是「人（Person）」这一类事物的实例，人有年龄属性。

## 三、推导规则

1. **叔叔规则**：如果 x 的父亲（或母亲）是 p，且 p 有一个兄弟 u，那么 u 是 x 的叔叔。
2. **姑姑规则**：如果 x 的父亲（或母亲）是 p，且 p 有一个姐妹 a，那么 a 是 x 的姑姑。
3. **祖父母规则**：如果 x 的父亲是 f，且 f 的父亲是 g，那么 g 是 x 的祖父。
4. **成年判定规则**：任何年龄大于等于 18 岁的人，自动归类为成年人；小于 18 岁的人归类为未成年人。成年人与未成年人互斥。
5. **逆关系规则**：如果 u 是 x 的叔叔，则 x 是 u 的侄子/侄女；如果 f 是 x 的父亲，则 x 是 f 的孩子。

## 四、应用场景

- 权限分级：只有成年人可以开通支付权限、发布内容。
- 内容推荐：按亲属关系推荐家庭相册的共享范围。
- 称谓生成：在家庭树页面自动为每位成员生成相对当前用户的称谓。

## 五、示例

登记了「张小雨的父亲是张大山」「张大山和张小海是兄弟」两条基础关系后，系统应自动推导出「张小海是张小雨的叔叔」，无需用户手工录入。同理，登记出生年份后系统自动判定：1988 年出生的张小海是成年人，2015 年出生的张小风是未成年人。
