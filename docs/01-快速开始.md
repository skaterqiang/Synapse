# 1. 快速开始

[← 返回目录](README.md)

## 1.1 环境要求

| 项目 | 要求 |
|---|---|
| Node.js | 18 及以上（推荐 20+） |
| npm | 随 Node.js 一并安装 |
| 操作系统 | macOS / Windows |

## 1.2 安装与启动

```bash
git clone https://github.com/skaterqiang/Synapse.git
cd Synapse
npm install
npm start
```

`npm start` 会先执行 `prestart` 钩子（`scripts/ensure-mac-sign.js`）对 Electron 做 ad-hoc 签名，避免 macOS 上被 Gatekeeper/XProtect 拦截。

### 其他启动方式

| 命令 | 用途 |
|---|---|
| `npm start` | 桌面开发模式（推荐） |
| `npm run web` | 浏览器模式（实验性），访问 `http://localhost:8787` |
| `npm run dist:mac` | 打包 macOS 安装包（`.pkg` / `.dmg`，产物在 `release/`） |
| `npm run dist:win` | 打包 Windows NSIS 安装包（产物在 `release/`） |

> 首次打开未签名的安装包时：macOS 右键选择「打开」；Windows 若被 SmartScreen 拦截，点「更多信息 → 仍要运行」。

## 1.3 配置大模型（必做）

除纯笔记编辑外，Wiki 吸收、图谱抽取、AI 问答都需要大模型。点击左下角 **⚙ 设置**，在「模型配置」页填写：

![设置 · 模型配置](images/settings-ai.png)

| 字段 | 说明 |
|---|---|
| **服务商 Provider** | 选择预设后自动带出 Base URL 与默认模型；也可选「自定义」 |
| **接口地址 (Base URL)** | 兼容 OpenAI 格式的接口地址 |
| **API Key** | 你的密钥，保存在本地数据库（界面上以圆点遮蔽显示） |
| **模型名称** | 如 `qwen3.8-max`、`gpt-4o`、`deepseek-chat` |
| 采样温度 temperature | 0–2，留空使用接口默认 |
| 核采样 top_p | 0–1，留空使用接口默认 |
| 最大 tokens max_tokens | 留空使用接口默认 |

内置服务商预设：**阿里云百炼（DashScope）**与 **Ollama（本地）**。两者均走兼容 OpenAI 的 `/chat/completions` 接口格式；阿里云需填 API Key，本地 Ollama 无需 Key。

填写后点右下角 **保存设置**。

## 1.4 界面总览

![主界面](images/notes-editor.png)

界面分为三栏，可拖拽分隔条调整宽度（双击复位）：

### 左侧导航栏

| 区块 | 说明 |
|---|---|
| 🔍 搜索框 | 全局搜索笔记 / 原始文件 / Wiki / 图谱 |
| 📝 **全部笔记** | 笔记总入口，右侧 `＋` 新建笔记；下方是**目录**树与**标签**云 |
| 🗄 **原始文件** | 待加工的原始资料管理，右侧 `＋` 添加 |
| 📖 **LLM Wiki** | 点击标题查看 Wiki 索引；右侧 `＋` 打开「吸收新来源」弹窗 |
| 📐 领域模版 | 领域抽取规则管理（数字为模版数量） |
| **知识图谱** | 5 个子视图：🧭 概览 / 📍 实体浏览 / 🪐 整体图谱 / 📘 本体定义 / 💬 KG 问答 |
| **作业管理** | 后台任务队列与进度 |
| 📜 提示词管理 | 自定义各能力的系统提示词 |
| 底部 | **⚙ 设置** 与 **✨ AI 问答** |

### 中间列表栏
随当前导航切换内容：笔记列表 / Wiki 页面索引 / AI 会话历史等。点击标题栏的 `«` 可收起。

### 右侧主区域
笔记编辑器，或各功能的整页视图（设置、作业、图谱、模版、原始文件等）。

## 1.5 5 分钟上手

1. **写一条笔记** — 点「全部笔记」右侧 `＋`，输入标题后在右侧编辑，支持编辑/分屏/预览三种模式
2. **配置模型** — 左下角 ⚙ 设置 → 模型配置 → 填 Base URL / API Key / 模型名 → 保存
3. **问一个问题** — 点左下角 ✨ AI 问答，输入问题，AI 会结合你的笔记/Wiki/图谱作答
4. **吸收一份资料** — 侧边栏「LLM Wiki」右侧 `＋` → 粘贴一个网址 → 开始吸收
5. **看后台进度** — 进入「作业管理」查看阶段进度；完成后回到「LLM Wiki」浏览生成的页面
6. **生成知识图谱** — 在笔记卡片或原始文件行上**右键** → 「提取知识图谱」→ 完成后进入「整体图谱」查看

## 1.6 数据存放位置

默认数据根目录为项目下的 `data/`（打包版为安装目录下的 `data/`），可在「设置 → 存储」中迁移。

| 内容 | 位置 |
|---|---|
| 数据库 | `<数据根目录>/knowledge.db` |
| 笔记 Markdown 文件 | `<数据根目录>/note/` |
| LLM Wiki 页面 | `<数据根目录>/llmwiki/` |
| 技能产物 | `<数据根目录>/artifacts/` |

> `.gitignore` 已排除 `data/`、`*.db`、`root-path.json`、`db-path.json` 等，含密钥的数据不会被提交。切勿把 API Key 硬编码进源码。
