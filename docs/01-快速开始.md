# 1. 快速开始

[← 返回目录](README.md)

## 1.1 环境要求

| 项目 | 要求 |
|---|---|
| Node.js | 18 及以上（推荐 20+） |
| npm | 随 Node.js 一并安装 |
| 操作系统 | macOS / Windows |

## 1.2 安装与启动

```bash
git clone https://github.com/skaterqiang/Synapse.git
cd Synapse
npm install
npm start
```

`npm start` 会先执行 `prestart` 钩子（`scripts/ensure-mac-sign.js`）对 Electron 做 ad-hoc 签名，避免 macOS 上被 Gatekeeper/XProtect 拦截。

### 其他启动方式

| 命令 | 用途 |
|---|---|
| `npm start` | 桌面开发模式（推荐） |
| `npm run web` | 浏览器模式（实验性），访问 `http://localhost:8787` |
| `npm run dist:mac` | 打包 macOS 安装包（`.pkg` / `.dmg`，产物在 `release/`） |
| `npm run dist:win` | 打包 Windows NSIS 安装包（产物在 `release/`） |

> 浏览器模式也可直接双击根目录的 `start-web.bat`（Windows）/ `start-web.command`（macOS）：自动核对依赖、启动服务并打开浏览器；端口可用 `--port` 或环境变量 `PORT` 修改（默认 8787）。

> 首次打开未签名的安装包时：macOS 右键选择「打开」；Windows 若被 SmartScreen 拦截，点「更多信息 → 仍要运行」。

## 1.3 配置大模型（必做）

除纯笔记编辑外，图谱抽取、AI 问答都需要大模型。点击左下角 **⚙ 设置**，在「模型配置」页填写：

![设置 · 模型配置](images/settings-ai.png)

现在支持**同时配置多个模型**，每个模型一张卡片，**第一张为默认模型**。点卡片标题行展开单独配置：

| 字段 | 说明 |
|---|---|
| **服务商 Provider** | 选择预设后自动带出 Base URL 与模型名 |
| **接口地址 (Base URL)** | 兼容 OpenAI 格式的接口地址 |
| **API Key** | 你的密钥，保存在本地数据库（界面上以圆点遮蔽显示）；本地 Ollama 无需 Key |
| **模型名称** | 如 `qwen3.8-max`；点「获取模型」可拉取可用模型列表下拉选择 |

其余模型卡可 **设为默认**（与当前默认互换）或 **删除**；AI 问答输入区可按 provider 两级切换任一已配置模型。

内置服务商预设：**阿里云百炼（DashScope）**与 **Ollama（本地）**。两者均走兼容 OpenAI 的 `/chat/completions` 接口格式；阿里云需填 API Key，本地 Ollama 无需 Key。

设置修改后**自动保存**（失焦即生效），无需点击保存按钮。

## 1.4 界面总览

![主界面](images/notes-editor.png)

界面分为三栏，可拖拽分隔条调整宽度（双击复位）：

### 左侧导航栏

| 区块 | 说明 |
|---|---|
| 🔍 搜索框 | 全局搜索笔记 / 原始文件 / 图谱 |
| 📝 **笔记** | 笔记总入口，右侧 `＋` 新建笔记；下方是**目录**树与**标签**云 |
| 🗄 **原始文件** | 待加工的原始资料管理，右侧 `＋` 添加 |
| **知识图谱管理** | 分区含 5 个子视图：🧭 概览 / 📍 实体浏览 / 🪐 整体图谱 / 📘 本体定义 / 💬 KG 问答，以及 📐 **领域模版**（数字为模版数量） |
| **作业管理** | 后台任务队列与进度 |
| 📜 提示词管理 | 自定义各能力的系统提示词 |
| 底部 | **⚙ 设置** 与 **✨ AI 问答** |

点侧边栏顶部的 `«` 可把整个侧边栏收起为一条**图标栏**（只留各导航图标，点击图标直达对应功能），再点图标栏上的展开按钮恢复；收起状态会被记住，重启后保持。

### 中间列表栏
随当前导航切换内容：笔记列表 / AI 会话历史等。点击标题栏的 `«` 可收起。

### 右侧主区域
笔记编辑器，或各功能的整页视图（设置、作业、图谱、模版、原始文件等）。

首次打开 ✨ **AI 问答** 时，欢迎页会展示两张**引导卡**：**基础配置**（1. 配置模型 / 2. 配置 MinerU 文档解析 / 3. 添加第一份原始文档）与**配置 MCP / 技能**（1. 添加 MCP 服务器 / 2. 启用一个技能），完成一项即点亮绿色勾并更新进度（如 3/3），点「开始配置」可直达对应页面。引导卡下方的 **📖 使用手册 · 在应用内查看详细步骤** 按钮可在应用内直接翻阅本套文档（无需离开应用）。

## 1.5 用原始文件问第一句话

以「把原始文件作为数据源」为例，完整走一遍从添加资料到问答的流程：

1. **添加原始文件** — 侧边栏点 🗄 **原始文件**，右侧 `＋` 可添加本机文件/目录，或粘贴网页 URL（登记链接并读取标题，正文在提取/问答时按需抓取；需登录站点可填账号密码）
2. **勾选知识源** — 点左下角 ✨ **AI 问答**，在输入框上方的知识源条勾选 🗄 **原始文件**
3. **提问** — 例如输入「看下有没有最新的新闻？」发送。AI 会在你添加的原始文件中做关键字检索，把命中片段注入上下文作答；回答下方展示**引用来源**，可回溯核对原文

> 想问联网最新信息，可在设置·MCP 中添加并启用 MCP 联网搜索服务器（已启用的 MCP 默认全部参与问答，可在输入框 🧩 菜单中去除/恢复）；想问自己积累的内容则勾选 📝 笔记 / 🗄 原始文件 / 🕸 知识图谱。多个知识源可任意组合，一个都不勾选时模型用自身知识回答。

各知识源的检索方式与引用规则详见 [3. AI 问答](03-AI问答.md#32-知识源选择)。

## 1.6 5 分钟上手

1. **写一条笔记** — 点「笔记」右侧 `＋`，输入标题后在右侧编辑，支持编辑/分屏/预览三种模式
2. **配置模型** — 左下角 ⚙ 设置 → 模型配置 → 填 Base URL / API Key / 模型名 → 保存
3. **问一个问题** — 点左下角 ✨ AI 问答，输入问题，AI 会结合你的笔记/原始文件/图谱作答
4. **提取一份资料** — 在「原始文件」中添加资料，右键选择「提取笔记」
5. **看后台进度** — 进入「作业管理」查看图谱任务进度
6. **生成知识图谱** — 在笔记卡片或原始文件行上**右键** → 「提取知识图谱」→ 完成后进入「整体图谱」查看

## 1.7 数据存放位置

默认数据根目录为项目下的 `data/`（打包版为安装目录下的 `data/`），可在「设置 → 存储」中迁移。

| 内容 | 位置 |
|---|---|
| 数据库 | `<数据根目录>/knowledge.db` |
| 笔记 Markdown 文件 | `<数据根目录>/note/` |
| 技能产物 | `<数据根目录>/artifacts/` |

> `.gitignore` 已排除 `data/`、`*.db`、`root-path.json`、`db-path.json` 等，含密钥的数据不会被提交。切勿把 API Key 硬编码进源码。
