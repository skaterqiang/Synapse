# 12. 语料库

[← 返回目录](README.md)

「语料（Corpus）」是本应用把**原始文件**加工成**知识图谱**之间的中间产物：抽取技能把 PDF/DOCX/图片/表格等解析成一篇篇**结构统一的 Markdown 语料**，落盘在 `<数据根目录>/corpus/` 下，再作为知识图谱抽取的输入。语料是**可重生成的机器产物**——它不进全局搜索、不随备份迁移，坏了或想换一套抽取规则，重新抽一次即可。

---

例如抽取 `供电容量说明.pdf` 后，目录如下（原文档名去掉扩展名）：

```text
corpus/
└── 供电容量说明/
    ├── 供电容量说明.md
    └── 供电容量说明.assets/   # 有图片时创建
```

不维护 `index.json` 或数据库索引；进入语料库或点击刷新时，直接扫描目录中的 Markdown 文件。领域信息保存在文件头，不决定存储目录。同名不同来源或技能的语料通过文件名后缀避免覆盖；旧版语料保留原路径，仍可读取，不自动迁移。

## 12.1 为什么需要语料库

以前「文件 → 图谱」是一步硬编码：每个文件现场解析、只喂模型开头一小段。拆出「语料」这一层后：

- **可复用**：同一份 PDF 解析一次存成语料，之后反复入图不必再解析（解析最贵）；
- **可审阅**：语料是纯 Markdown，能直接读、能一键提升成笔记再手工修订；
- **可插拔**：解析、抽取、分块、护栏、合并这些环节被拆成可组合的「装饰器」，换一种抽取规则只是换技能，不用改流程。

---

## 12.2 语料库子页签

在**原始文件页**顶部有一个分段控件：**原始文件 / 语料库**，两者共用同一视图框架。

![原始文件管理](images/raw-files.png)

「语料库」子页签列出所有已落盘的语料，支持：

| 操作 | 说明 |
|---|---|
| 按领域/名称筛选 | 顶部搜索框按名称、领域、本体体系模糊过滤；领域分段可切换 |
| 预览 | 点条目在应用内预览该语料的 Markdown 正文（复用原始文件的预览视图，含 `.assets/` 图片） |
| 右键菜单 | 打开所在目录、提升为笔记、删除等 |
| 陈旧提示 | 源文件在被抽取后又改动过（mtime 变化）的语料会标记「待更新」 |

> 语料只在**本子页签内**按自己的关键词过滤，**不参与全局搜索与 AI 问答**——「语料库」视图是它的唯一入口。

### 12.2.1 抽取为语料

在**原始文件页**（非语料库页签）勾选文件，右键「**抽取为语料**」（或在批量操作里选），会提交一个 `extract-corpus` 作业：只解析、落盘语料，**不入图、不写笔记**。作业在作业管理页可见，完成时提示本次写入的语料篇数；若单作业 LLM 调用数超过 100，卡片上会给出软预算提示（不阻断）。

> 右键「抽取为语料」入口与流水线总闸一致——需在「设置 → 语料流水线」勾选「启用语料流水线」后出现。

### 12.2.2 提升为笔记

语料是机器产物，常需要变成可编辑的笔记。选中一篇语料「**提升为笔记**」，指定目标目录即可——它会用同一 `source` 去重：**重复提升只会更新同一篇笔记，不会堆副本**。

## 12.3 抽取技能（`kind: extract`）

抽取技能是一种新技能类型，专职「文件 → Markdown 语料」。它与既有的「指令技能」共存、互不影响。

### 12.3.1 两种模式

| 模式 | 机制 | 适用 |
|---|---|---|
| `mode: llm` | SKILL.md 指令 + 模型直读文档 → Markdown | 常规文档、需要按指令重组结构的场景 |
| `mode: script` | 技能目录里的脚本在子进程沙盒执行，产出 Markdown 文件 | 需要专用工具（如 OCR）的场景 |

> `mode: script` 的产物**通过文件交接**（脚本把结果写到输出目录下的 Markdown 文件，应用读回后删除），不走标准输出——避免长文被截断。

### 12.3.2 SKILL.md 字段

```markdown
---
name: extract-markdown
description: 通用文档 → 规范 Markdown 语料
kind: extract            # 技能类型：instructions（默认）或 extract
accepts: [md, pdf, docx] # 适用扩展名；留空 = 通配所有类型
mode: llm                # llm（默认）或 script
entry: scripts/main.js   # mode:script 的入口脚本（相对技能目录）
priority: 50             # 同一扩展名命中多个技能时的排序（大者优先）
version: 1.0.0
enabled: true            # 缺省 true；可先植入但默认关（如依赖额外环境）
timeoutSec: 120          # mode:script 子进程超时（秒），留空回退全局设置
output: corpus-out.md    # mode:script 的产物文件名（相对输出目录）
---

（正文即抽取指令，告诉模型如何把文档整理成规范 Markdown）
```

`kind`、`accepts`、`mode`、`entry`、`priority`、`version`、`enabled`、`timeoutSec`、`output` 均为可选字段，缺省时行为与普通指令技能一致（`kind` 默认 `instructions`）。

### 12.3.3 内置示例技能

首次启动会自动植入 4 个示例抽取技能（位于工作区级 `skills/`，以目录引用方式登记，不复制副本）：

| 技能 | 适用 | 模式 | 默认启用 |
|---|---|---|---|
| `extract-markdown` | 通用（留空 = 通配所有类型） | llm | ✅ |
| `extract-table` | xlsx / xls / csv（宽表转记录式小节） | llm | ✅ |
| `extract-slide` | pptx（按页组织 + 演讲者备注） | llm | ✅ |
| `extract-ocr` | png / jpg / jpeg / tiff | script | ⛔ 示例，默认关（需本机安装 tesseract） |

### 12.3.4 选择规则

同一文件扩展名可能命中多个抽取技能，选取遵循三条规则：

1. **只有 `kind: extract` 且已启用的技能参与**（指令技能永不入选）；
2. **按 `priority` 降序**、同分按名称升序；`accepts` 命中的技能优先于通配技能；
3. **默认只取 1 个**（可在「设置 → 语料流水线」用「抽取技能注入数 TopN」放宽到 1–5）。

若没有任何匹配的启用抽取技能，该文件的解析会回退到「文档解析」页配置的内置解析 / MinerU 路径。

### 12.3.5 在技能页创建与试跑

设置 → 技能页：

- 顶部可按 **全部 / 指令 / 抽取** 三态筛选；抽取技能卡片带类型徽标；
- **编辑弹窗**（抽取技能）多出 6 个字段：类型、适用扩展名、模式、脚本入口、优先级、超时；`mode: script` 时还会显示脚本入口/产物名/超时字段；
- **试跑**：上传一个本机样本文件，点「试跑抽取」即时运行该技能（llm 走模型、script 走子进程），下方展示产出的 Markdown 与耗时、解析方式，便于在正式批量抽取前验证技能指令是否合用。

## 12.4 装饰器流水线（工作原理）

「文件 → 图谱」在开启语料流水线后，被表达为一条**从内向外层层装饰**的链（类比 `new BufferedInputStream(new FileInputStream(f))`）。每一层实现同一套统一接口，负责一件事，可单独测试、可插拔替换：

```
Source（收集来源）
  → Log（作业阶段/日志）
  → Filter（扩展名白名单；去重接线点，默认关）
  → [CorpusReuse]（可选：命中未过期语料直接复用，跳过解析）
  → Fallback[ MinerU | 抽取技能 | 内置解析 ]（解析：bytes → text）
  → Cache（解析缓存，短路整条解析）
  → CorpusWrite（落盘为 corpus/**/*.md）
  → Enrich（领域/本体体系归属）
  → Chunk（长文按分块大小切块）
  → Extract（AI 本体抽取：text → nodes/edges）
  → Guard（写入护栏）
  → MergeGraph（合并存图 + 推理物化）
```

- **拉取式**：同一时刻只有一条语料在链上流动，不累积内存；
- **层序有硬约束**（如缓存必须在解析外层、落盘必须在分块内层、复用必须在缓存内层/解析外层），构建期会静态校验，写错直接报错；
- **单条失败不断流**：某个文件解析失败只记一条错误并跳过，其余照常处理；
- 三条默认配方对应三类作业：`graph`（提取知识图谱）、`corpus`（抽取为语料）、`note`（提取笔记）。

## 12.5 相关设置

语料流水线的 7 个设置项（3 个开关 + 4 个数值）见 [10.10 语料流水线](10-设置.md#1010-语料流水线)。要点：

- **启用语料流水线**默认关——未勾选时「提取知识图谱」走原有实现，产物逐字段等价；
- **抽取时同时落盘语料**默认开；
- **复用未过期语料**默认关（改技能指令后期望重新抽取）。
