# 9. 提示词管理

[← 返回目录](README.md)

Synapse 的每一项 AI 能力背后都有一条**系统提示词**。提示词管理页把它们全部集中暴露出来，你可以查看内置默认值并按需覆盖——这是调优 AI 输出质量最直接的手段。

点击侧边栏 **📜 提示词管理** 进入。

![提示词管理](images/prompts-manager.png)

## 9.1 可配置的提示词清单

共 11 条，覆盖全部 AI 能力：

| 名称 | 作用场景 |
|---|---|
| **AI 辅助 · 润色** | 编辑器 ✨ AI 按钮的改写/润色 |
| **AI 问答 · 助手** | 笔记 AI 问答面板的人设（留空则不注入） |
| **吸收 · 编译** | 吸收作业阅读来源并生成 Wiki 页面计划 |
| **吸收 · 领域匹配** | 判定来源所属的领域模版 |
| **图谱 · 本体抽取** | 从来源中抽取节点与关系 |
| **图谱 · 实体识别** | 从问题中抽取候选实体名（KG 问答第一步） |
| **图谱 · 问答** | 依据图谱事实与原文材料回答 |
| **Wiki · 选页** | 从页面清单中选出最相关的页面 |
| **Wiki · 问答** | 基于所选页面生成回答 |
| **Wiki · 体检** | 通读全部页面生成健康检查报告 |
| **模版 · 生成/建议** | 自动生成 / 智能建议领域模版 |

## 9.2 卡片操作

每条提示词以一张卡片呈现，包含名称、用途说明与文本编辑区。

| 按钮 | 作用 |
|---|---|
| **保存** | 保存当前内容为自定义提示词 |
| **✎ 全屏编辑** | 在主框架内全屏编辑长提示词 |
| **恢复默认** | 清除自定义值，回填内置默认文本 |

**重要行为**：卡片打开时若你尚未自定义，文本区会**预填内置默认值**。这意味着你可以在默认提示词的基础上做增量修改，而不必从零重写。

点「恢复默认」后同样会回填默认文本，你可以继续在其基础上修改再保存。

## 9.3 全屏编辑

长提示词在小文本框里编辑很不方便，点 **✎ 全屏编辑** 会在主框架内打开一个全屏编辑页：

- 顶部显示提示词名称与用途说明
- 大面积文本编辑区
- 可**保存**并返回，或直接返回（若有未保存修改会提示确认）
- 也提供**恢复默认**

## 9.4 覆盖机制

运行时的取值逻辑很简单：

```
设置中的自定义值（非空） || 内置默认值
```

- 自定义值保存在本地数据库的设置中
- 留空即视为未自定义，自动使用内置默认
- 覆盖立即生效，无需重启

## 9.5 调优建议

| 目标 | 建议修改的提示词 |
|---|---|
| Wiki 页面结构/风格不符合预期 | 吸收 · 编译（也可优先调整**领域模版**的字段，粒度更细） |
| 领域总是判定为 general | 吸收 · 领域匹配（并检查领域模版的关键词是否有区分度） |
| 图谱节点太碎 / 太笼统 | 图谱 · 本体抽取（同时收紧**本体定义**的实体类与谓词） |
| 问答不引用出处 | Wiki · 问答 / 图谱 · 问答（强调必须标注来源） |
| 希望 AI 用特定语气或身份作答 | AI 问答 · 助手 |
| 体检报告维度不合需求 | Wiki · 体检 |

### 编写要点

1. **保留格式约定** — 涉及 JSON 输出的提示词（吸收编译、领域匹配、图谱抽取、选页、模版生成）必须保留「只输出合法 JSON」及其字段结构的要求，否则会触发「模型返回无法解析」错误
2. **保留语言约定** — 内置提示词大多要求「思考与输出均使用中文」，如需其他语言在此处调整
3. **小步试错** — 一次只改一处，通过作业页的实时输出观察效果
4. **随时可回退** — 「恢复默认」永远可用，不必担心改坏

> 领域模版与本体定义是**结构化**的约束（字段清晰、粒度细），提示词是**自由文本**的约束。优先用前两者调整抽取行为，效果更稳定可控；提示词更适合调整整体风格、语气与输出规范。
