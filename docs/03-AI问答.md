# 3. AI 问答

[← 返回目录](README.md)

AI 问答是 Synapse 的统一对话入口。它不只是普通聊天——回答会结合你的**笔记、LLM Wiki、知识图谱**，还可以调用**联网搜索（MCP）**与**技能（Skills）**生成真实的办公文件。

点击左下角 **✨ AI 问答** 进入。

![AI 问答](images/ai-chat.png)

## 3.1 界面说明

| 区域 | 说明 |
|---|---|
| 中间列 | **＋ 新的任务** 按钮 + 历史会话列表（按日期排列），点击任一会话可继续对话 |
| 右侧主区 | 对话内容区；新会话显示「请输入您要完成的任务」 |
| 底部输入框 | 输入问题，点 **发送**（或回车）提交 |
| 输入框下方图标 | 📚 数据源 / 🧩 MCP 服务器 / ⚡ 技能 三个开关菜单 |
| 最底部快捷按钮 | 「你能做些什么」「写一份研究报告」「总结当前知识库」「检索相关知识」等一键提问 |

## 3.2 数据源选择（📚）

点输入框下方的 📚 图标可勾选本轮问答参考哪些数据源：

| 数据源 | 作用 |
|---|---|
| 📝 **笔记** | 按问题检索相关笔记，把正文注入上下文 |
| 📖 **Wiki** | 两步检索：先让模型从页面清单中挑出最相关的页面，再读取这些页面内容作答 |
| 🕸 **知识图谱** | 按问题召回相关实体及其关系，作为事实依据注入 |

三者可任意组合。回答下方会展示**引用来源**（Wiki 页面路径、命中的图谱实体），便于溯源核对。

> Wiki 问答最多引用页数可在「设置 → 问答 → Wiki 问答最大引用页数」中调整（默认 5）。

## 3.3 会话管理

- **＋ 新的任务** — 开启一个全新会话
- 会话历史保存在本地数据库，跨应用重启保留
- 点击历史会话即可回看或继续追问
- 对话具备上下文记忆，可以直接追问「再详细讲讲第二点」

## 3.4 思考过程展示

若使用推理型模型（如带 thinking 的模型），模型的思考过程会以**可折叠区块**实时显示在回答上方，默认收起，点击展开。这样既能看到推理链路，又不会干扰阅读最终答案。

同时，AI 调用工具的步骤（工具名、参数、返回结果摘要）也会以步骤块的形式展示，整个过程透明可见。

## 3.5 澄清问题机制

当任务明显开放且缺少关键约束（例如「写一份研究报告」没说方向、格式、受众），AI 不会盲目开工，而是先返回一组**选择卡片**向你确认：

- 整个任务最多问一次
- 最多 3 个问题，每题 2–5 个选项
- 支持单选与多选

你选择后，AI 才基于确认过的约束正式作答。普通提问或信息已充分时不会触发此机制。

## 3.6 联网搜索（🧩 MCP）

点 🧩 图标可勾选已配置的 MCP 服务器。Synapse 内置了阿里云百炼 **WebSearch** 服务（首次启动自动植入，API Key 复用模型配置，无需重复填写）。

行为说明：

- 勾选搜索类服务后，系统会**强制执行一次联网搜索**（不依赖模型自主决定），并把结果注入上下文
- 若工具装载失败，会下发告警步骤，且提示词中会剔除 MCP 相关描述，避免模型「声称已搜索」但实际没搜
- 搜索的查询词与结果摘要都会在步骤块中展示

MCP 服务器的配置方式见 [10. 设置](10-设置.md#106-mcp)。

## 3.7 技能（⚡ Skills）

技能是一组遵循 `SKILL.md` 规范的能力包（与主流 Agent 生态的技能格式兼容）。点 ⚡ 图标可勾选启用。

**可执行技能**：当启用了名称含 `docx` / `pptx` / `xlsx` 的技能时，AI 会获得一个脚本执行工具，能够编写并运行 Node.js 脚本，生成**真实的办公文件**：

| 文件类型 | 使用的库 |
|---|---|
| `.docx` | `docx` |
| `.pptx` | `pptxgenjs` |
| `.xlsx` | `exceljs` |

生成的文件保存到 `<数据根目录>/artifacts/`，并在对话中以 **📄 产物卡片**呈现，点卡片上的按钮即可用系统默认程序打开。

执行环境的安全边界：仅允许 node 解释器、限定输出目录、超时自动 kill（默认 60 秒，上限 180 秒）、结束后清理进程树。

技能的添加与管理见 [10. 设置](10-设置.md#107-技能)。

## 3.8 其他问答入口

除主框架 AI 问答页外，还有两个专门入口：

| 入口 | 位置 | 特点 |
|---|---|---|
| **Wiki 问答** | LLM Wiki 页面内 | 专注于 Wiki 内容，两步检索选页后作答，可把回答**归档**为 Wiki 页面 |
| **KG 问答** | 知识图谱 → 💬 KG 问答 | 基于图谱做多跳推理，沿实体回溯原文材料，见 [7. 知识图谱](07-知识图谱.md#75-kg-问答) |

## 3.9 使用建议

- **问事实性/最新信息** → 勾选 MCP 联网搜索
- **问自己积累的知识** → 勾选笔记 + Wiki
- **问概念之间的关系** → 勾选知识图谱
- **要生成文档/报告文件** → 启用对应的 docx/pptx/xlsx 技能
- 若回答质量不理想，可在「提示词管理」中定制该场景的系统提示词
