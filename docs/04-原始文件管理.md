# 4. 原始文件管理

[← 返回目录](README.md)

「原始文件」是知识加工流水线的**入口**：先把待加工的资料收集到这里，再从这里发起「提取 Wiki」或「提取知识图谱」。

点击侧边栏 **🗄 原始文件** 进入。

![原始文件管理](images/raw-files.png)

*上图为尚无原始来源时的空状态，顶部工具栏提供 4 种添加方式。*

## 4.1 核心设计：引用式管理

Synapse 对本机文件采用**引用式**管理——**不复制副本**，只记录本机路径。

这样做的好处：

- 不重复占用磁盘空间
- 源文件更新后，Synapse 侧自动感知（列表实时反映文件的大小与修改时间）
- 「解除引用」不会删除你的本机文件

对于**目录引用**，Synapse 会在每次打开列表时**实时遍历**源目录，因此你在源目录里新增或删除文件，列表会同步变化，无需重新导入。

## 4.2 添加来源

顶部工具栏 4 个按钮：

| 按钮 | 说明 |
|---|---|
| **＋ 添加文件** | 选择一个或多个本机文件（引用式，不复制） |
| **＋ 添加目录** | 引用整个目录，保留多级结构，实时遍历 |
| **🔗 添加链接** | 抓取网页正文，转为 Markdown 存入 `raw/` |
| **📝 添加文本** | 粘贴文本内容，存为 Markdown 存入 `raw/` |
| **🔄 刷新** | 重新扫描列表 |

### 支持的文件格式

| 类别 | 扩展名 |
|---|---|
| 文档 | `pdf`、`docx` |
| 表格 | `xlsx`、`xls`、`csv` |
| 演示 | `pptx` |
| 文本/标记 | `md`、`markdown`、`txt`、`html`、`htm` |

各格式的文本提取方式：PDF 抽取文本层；DOCX 转 HTML 再转 Markdown；Excel 按工作表转 CSV；PPTX 按幻灯片抽取文本；HTML 转 Markdown。

> 提取是**按需**进行的：文件原样保留，只有在真正要吸收或抽取时才提取文本。因此添加过程很快。

### 目录引用的排除规则

遍历目录时自动跳过以下依赖/构建/隐藏目录，避免噪音：

`.venv`、`node_modules`、`.git`、`.idea`、`.vscode`、`.qoder`、`__pycache__`、`.DS_Store`、`dist`、`build`、`target`

## 4.3 列表信息

每行显示：文件名、扩展名、大小、修改时间，以及**吸收状态**标记。

### 吸收状态

| 状态 | 含义 |
|---|---|
| 无标记 | 尚未吸收 |
| 已吸收 + 时间 | 该来源已成功吸收过 |
| **已修改**（stale） | 吸收之后源文件又被改动过，建议重新吸收 |

重复吸收保护：提交吸收作业时，已吸收且未检测到修改的来源会被自动跳过；若全部来源都已吸收过，会提示你确认是否强制重新吸收。

## 4.4 发起知识加工

在文件行或目录行上**右键**：

| 菜单项 | 作用 |
|---|---|
| 📝 提取 Wiki | 把该来源吸收为结构化 Wiki 页面 |
| 🕸 提取知识图谱 | 从该来源抽取实体与关系加入图谱 |

在**目录行**右键时会对该目录下所有文件批量处理。提交后进入 [作业管理](08-作业管理.md) 查看进度。

## 4.5 查看与移除

- **查看** — 点击行内查看按钮，用本机默认软件打开原始文件（网页模式不支持）
- **移除** — 行为取决于来源类型：

| 来源类型 | 移除行为 |
|---|---|
| 单文件引用（`local:`） | 从引用清单移除，**不删除本机文件** |
| 目录引用下的文件 | 加入排除集，**不删除本机文件** |
| 目录引用整体（「解除」按钮） | 移除目录引用及其下的单文件引用与排除项，**不删除任何本机文件** |
| `raw/` 下由链接/文本生成的文件 | 真正删除该文件 |

> 目录行上有醒目的「解除」按钮，用于一次性解除整个目录的引用关系。

## 4.6 raw/ 目录的组织

```
<数据根目录>/llmwiki/raw/
├── _auto/                 # 由「添加链接」「添加文本」及吸收笔记自动生成的 Markdown
│   └── 2026-08-22-xxx.md
└── （其他用户自建子目录）
```

`raw/_auto/` 下的自动生成内容不纳入「原始文件」列表管理——该列表只呈现你从本机添加的文件与目录，保持界面聚焦。

> 按 OKF 约定，`raw/` 是**不可变原始源层**，AI 只读不写；每次新增来源都是新建文件，不会覆盖历史。
