# 供电容量说明

> 阳光花园小区地下停车位充电桩扩容项目 · 供电容量核算文件
> 出具方：小区物业工程部 ｜ 日期：2026-08-20

## 一、现有供电设施

本小区地下车库供电由一台 **10kV 配电变压器**（下称"配变"，即 transformer）专供，型号 S13-M-630，额定容量 **630 kVA**。

配变下级设 **低压配电柜** 一面（GGD 型，8 回路），负责车库照明、排水泵、风机及现有 12 个慢充桩的供电。

## 二、现有负荷

| 负荷项 | 功率 |
| --- | --- |
| 车库照明与风机 | 45 kW |
| 排水泵 | 15 kW |
| 现有 12 个慢充桩（3.5kW，同时使用率 0.8） | 33.6 kW |
| 其他公共设施分摊 | 286.4 kW |
| **现有负荷合计** | **380 kW** |

## 三、扩容方案负荷估算

本次拟新增 **20 个停车位充电桩**，单桩额定功率 **7 kW**。

按经验安全值，充电桩群**同时使用率取 0.8**：

```
新增负荷 = 20 车位 × 7 kW × 0.8 = 112 kW
合计负荷 = 380 kW（现有） + 112 kW（新增） = 492 kW
```

492 kW < 630 kVA（按功率因数 0.95 折算约 598.5 kW），**变压器容量满足扩容要求**，无需增容更换。

## 四、结论与建议

1. 现有配变容量充足，扩容方案在供电容量维度**可行**。
2. 新增充电桩群应接入低压配电柜备用回路，电缆按 1.2 倍额定电流选型。
3. 若未来继续扩容至 40 桩以上，需重新核算配变容量，届时可能涉及增容（费用将翻倍）。
