# 施工安全规范

> 地下停车位充电桩安装施工安全规范（本项目专用）
> 适用：阳光花园小区地下车库充电桩扩容施工全过程

## 一、施工前要求

1. 施工单位须持有效电力设施承装（修、试）资质，人员持证上岗。
2. 开工前办理动火作业票、临时用电作业票，报物业工程部备案。
3. 施工区域设置围挡与警示标识，与非施工车位物理隔离。

## 二、电气安全

1. 所有接线作业必须在**低压配电柜对应回路断电、验电、挂牌**后进行，严禁带电作业。
2. 充电桩供电回路须独立设置漏电保护（动作电流 ≤ 30mA，动作时间 ≤ 0.1s）。
3. 电缆桥架与消防管线间距 ≥ 0.3m，穿越防火分区处做防火封堵。
4. 每台充电桩外壳须可靠接地，接地电阻 ≤ 4Ω。

## 三、消防与通风

1. 施工动火点 5m 范围内不得存放可燃物，现场配置 2 具 4kg 干粉灭火器。
2. 充电区域消防设施（喷淋、烟感）改造须先经消防部门备案。
3. 地下车库施工期间保持风机运行，不得封闭通风口。

## 四、验收标准

1. 绝缘电阻测试 ≥ 0.5MΩ，接地连续性测试合格。
2. 充电桩群同时使用率按 **0.8** 整定限流，防止超出配变承载能力。
3. 竣工资料（含隐蔽工程照片）移交物业存档，方可送电。

## 五、应急要求

- 施工现场发生电气火灾时，先断低压配电柜对应回路电源，再行灭火，严禁用水带电灭火。
- 触电事故处置：断电 → 脱离电源 → 心肺复苏 → 拨打 120，同步报告物业值班室。
