# 申请材料清单

> 停车位充电桩扩容 · 报装申请材料清单
> 依据：市供电公司《居民区充电设施报装指引（2026 版）》

## 一、必交材料（缺一不可）

扩容申请须随附以下材料，**少于 3 项将直接退回**：

1. **车位产权或使用证明** —— 20 个拟改造车位的产权证或长期租赁合同复印件。
2. **供电容量说明** —— 由物业工程部出具，载明配变容量、现有负荷与扩容负荷估算（见本项目《供电容量说明》）。
3. **施工安全规范承诺书** —— 物业与施工单位双章，承诺按《施工安全规范》执行。
4. **业主委员会同意函** —— 业委会盖章的扩容决议或业主表决结果（双过半）。
5. **充电桩设备合格证明** —— 拟采购充电桩的 CCC 认证证书与型式试验报告。

## 二、选交材料（视情况补充）

- 人防区域改造审批表（若车位位于人防工程范围内）。
- 消防部门备案回执（涉及喷淋/烟感改造时）。
- 增容申请表（仅当配变容量不足时，本项目暂不需要）。

## 三、提交方式

- 纸质材料一式两份，交市供电公司营业厅 3 号窗口；
- 电子版（PDF）同步上传供电公司"网上国网"平台；
- 受理时限：材料齐全后 5 个工作日内出具供电方案答复。

## 四、常见退回原因

| 退回原因 | 占比 |
| --- | --- |
| 材料项数不足（少于 3 项） | 41% |
| 容量说明缺少负荷估算过程 | 27% |
| 业委会同意函未盖章 | 18% |
| 其他 | 14% |
