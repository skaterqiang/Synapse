# 诊断学 · 课程资料卡

> 课程定位：研究采集病史、体格检查与辅助检查以形成诊断的基本技能，是进入临床的桥梁课。
> 本体映射：`mu:ClinicalFinding` / `mu:Symptom` / `mu:Sign` / `mu:DiagnosticProcedure` 及其子类

## 知识框架（章节级，原创纲要）

1. 绪论与病史采集：问诊方法、主诉、现病史、既往史、个人史与家族史
2. 常见症状：发热、疼痛（头痛/胸痛/腹痛）、咳嗽与咳痰、咯血、呼吸困难、心悸、水肿、恶心呕吐、呕血便血、黄疸、意识障碍
3. 体格检查：基本方法（视/触/叩/听/嗅）、一般状态、头颈部、胸部（肺与心脏）、腹部、生殖器与直肠、脊柱与四肢、神经系统
4. 辅助检查：心电图（正常与常见异常）、影像学基础（X线/CT/MRI/超声）、实验室检查（血/尿/粪便常规、生化、凝血）、内镜与穿刺活检
5. 病历书写：门诊病历、住院病历（入院记录/病程记录/出院记录）
6. 诊断思维：诊断步骤与临床思维方法、循证医学与诊断、鉴别诊断

## 核心概念清单（对齐本体）

| 概念 | 本体类 / 谓词 |
|---|---|
| 症状（发热/疼痛/呼吸困难…患者主观） | `mu:Symptom` |
| 体征（杂音/啰音/肝脾肿大…医师检出） | `mu:Sign` |
| 主诉（症状+持续时间） | `mu:ChiefComplaint` |
| 综合征（肾病综合征/代谢综合征） | `mu:Syndrome` |
| 体格检查 | `mu:PhysicalExamination` |
| 实验室检查（血/尿/生化/病理/微生物） | `mu:LaboratoryTest` 及子类 |
| 影像检查（X线/CT/MRI/超声） | `mu:ImagingStudy` 及子类 |
| 电生理检查（心电图/脑电图） | `mu:ElectrophysiologyTest` |
| 内镜检查（胃镜/肠镜/支气管镜） | `mu:EndoscopyTest` |
| 疾病→临床表现 | `mu:hasClinicalFinding` / `mu:hasSymptom` / `mu:hasSign` |
| 疾病→确诊手段 | `mu:diagnosedByProcedure` |
