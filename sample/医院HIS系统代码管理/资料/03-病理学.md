# 病理学 · 课程资料卡

> 课程定位：研究疾病发生发展中的形态结构改变与机制，是基础医学与临床医学的桥梁课。
> 本体映射：`mu:PathologicalProcess` 及其 9 个子类、`mu:causesPathologicalProcess` / `mu:leadsToDisease`

## 知识框架（章节级，原创纲要）

1. 细胞和组织的适应与损伤：萎缩/肥大/增生/化生、变性、坏死与凋亡
2. 损伤的修复：再生、纤维性修复、创伤愈合
3. 局部血液循环障碍：充血与淤血、出血、血栓形成、栓塞、梗死
4. 炎症：基本病理变化（变质/渗出/增生）、类型、结局、全身反应
5. 肿瘤：概念与形态、异型性、生长与转移、命名与分类、病因与发病机制、常见举例
6. 环境与营养性疾病、遗传性疾病与儿童疾病（概论）
7. 心血管系统疾病：动脉粥样硬化、冠心病、高血压、风湿病、感染性心内膜炎、瓣膜病、心肌病与心肌炎
8. 呼吸系统疾病：肺炎、慢性阻塞性肺疾病、肺硅沉着症、鼻咽癌与肺癌
9. 消化系统疾病：胃炎、消化性溃疡、病毒性肝炎、肝硬化、消化道常见肿瘤、肝癌
10. 淋巴造血系统疾病：淋巴结良性病变、淋巴瘤、白血病
11. 泌尿系统疾病：肾小球疾病、肾小管-间质疾病、肾与膀胱常见肿瘤
12. 生殖系统与乳腺疾病、内分泌系统疾病、神经系统疾病
13. 感染性疾病：结核病、伤寒、细菌性痢疾、性传播疾病

## 核心概念清单（对齐本体）

| 概念 | 本体类 / 谓词 |
|---|---|
| 炎症 | `mu:Inflammation` |
| 缺血 / 缺氧 | `mu:Ischemia` / `mu:Hypoxia` |
| 坏死 | `mu:Necrosis` |
| 纤维化 | `mu:Fibrosis` |
| 肿瘤形成 | `mu:Neoplasia` |
| 出血 / 血栓形成 | `mu:Hemorrhage` / `mu:Thrombosis` |
| 休克 | `mu:Shock` |
| 病因→病理过程（血栓形成→缺血） | `mu:causesPathologicalProcess` |
| 病理过程→疾病（纤维化→肝硬化、动脉粥样硬化→冠心病） | `mu:leadsToDisease` |
| 疾病累及器官（肺炎→肺） | `mu:affectsStructure` |
