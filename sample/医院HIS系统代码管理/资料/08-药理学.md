# 药理学 · 课程资料卡

> 课程定位：研究药物与机体相互作用规律，为临床合理用药提供理论依据。
> 本体映射：`mu:Drug` 及 7 个药理亚类、`mu:hasIndication` / `mu:hasContraindication` / `mu:hasAdverseEffect`

## 知识框架（章节级，原创纲要）

1. 总论：药动学（吸收/分布/代谢/排泄）、药效学（作用机制/量效关系/受体理论）、影响药物作用的因素与合理用药
2. 传出神经系统药理：胆碱受体激动药与抗胆碱酯酶药、M/N 胆碱受体阻断药、肾上腺素受体激动药、抗肾上腺素药
3. 中枢神经系统药理：镇静催眠药、抗癫痫与抗惊厥药、抗精神病药、抗帕金森药、镇痛药（阿片类）、解热镇痛抗炎药、全身麻醉药
4. 心血管系统药理：抗高血压药、抗心绞痛药、抗心律失常药、抗慢性心功能不全药、调血脂药、抗血栓药
5. 内脏系统药理：利尿药与脱水药、子宫平滑肌兴奋药、平喘镇咳祛痰药、抗消化性溃疡药、抗组胺药
6. 内分泌系统药理：肾上腺皮质激素、甲状腺激素与抗甲状腺药、胰岛素与口服降糖药、性激素与避孕药
7. 化学治疗药理：抗生素（β-内酰胺/大环内酯/氨基糖苷/喹诺酮）、合成抗菌药、抗结核与抗麻风药、抗真菌与抗病毒药、抗寄生虫药、抗恶性肿瘤药
8. 药物开发与药物警戒：新药研发流程、不良反应监测、药物相互作用

## 核心概念清单（对齐本体）

| 概念 | 本体类 / 谓词 |
|---|---|
| 抗生素（青霉素/头孢/大环内酯/喹诺酮） | `mu:Antibiotic` |
| 降压药（利尿剂/ACEI/ARB/CCB/β阻滞剂） | `mu:Antihypertensive` |
| 降糖药（胰岛素/双胍/磺脲/SGLT-2） | `mu:Antidiabetic` |
| 抗凝药（肝素/华法林/NOAC/抗血小板） | `mu:Anticoagulant` |
| 镇痛药（NSAIDs/阿片类） | `mu:Analgesic` |
| 麻醉药（全麻/局麻） | `mu:Anesthetic` |
| 激素类药物（糖皮质激素/甲状腺激素/性激素） | `mu:Hormone` |
| 中草药（中医药理论指导） | `mu:HerbalMedicine` |
| 生物制剂（单抗/疫苗/细胞因子） | `mu:BiologicalAgent` |
| 药物→适应症 | `mu:hasIndication` |
| 药物→禁忌症（β阻滞剂→哮喘、华法林→活动性出血） | `mu:hasContraindication` |
| 药物→不良反应（青霉素过敏、化疗骨髓抑制） | `mu:hasAdverseEffect` |
| 疾病→药物治疗 | `mu:treatedByDrug` |
