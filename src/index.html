领域模版管理
新建领域模版

领域模版是告诉 AI「在这个领域里该关注什么、忽略什么、产物怎么组织」的规则集。吸收文档时，下面三组规则会作为领域约束注入提示词。

名称和描述都填写后才能生成：自动补全三组规则——领域定位、抽取规则、产物组织（ID、关键词、实体/概念类型、必提/忽略、质量与页面骨架）
无需填写：创建时留空自动生成（AI 生成会按领域语义回填） 

        

        

        
① 领域定位让 AI 认得这个领域：吸收新文档时先依据描述与关键词判定「属于哪个领域」

        
        
        
        
        
        
        

        

        
② 本体体系绑定该领域用哪套顶层本体归类：选定后下方领域类/谓词随之切换数据源；提取时自动带上对应体系

        
        
        

        

        

        
③ 领域类（挂在体系类树上）勾选体系类直接纳入，或在其下添加领域子类；提取时节点优先归入这些类

        

          

          

            
已选领域类 0

            

            
          

        

        
请至少勾选或添加一个领域类

        

        

        
④ 领域谓词勾选体系谓词或定义领域专用谓词（可选）；提取时关系优先使用这些谓词

        

        
        

        

        
⑤ 抽取规则必须提取不得遗漏，忽略内容直接丢弃

        
        
        
        
        

        

        
⑥ 产物组织产物怎么组织：页面骨架决定产物的章节结构，质量标准约束内容写法

        
        

        
        
请至少添加一个骨架页面并填写标题

模型

              
兼容 OpenAI 接口格式。每个模型一张卡片，默认收起，点标题行展开单独配置；第一张为默认模型，其余可在 AI 问答输入区按 provider 两级选择

              

              
              

                

                  
                  
                  
                  
                  
                  
                  
                  

                    

                      
                      
                      

                    

                    
                  

                  
点「获取模型」拉取可用模型；点输入框右侧 ▾ 下拉选择全部已获取模型

                  

                    
                    修改上方配置后点「保存修改」写入，保存后立即生效
                  

                

              


              
生成参数

              
对所有模型生效（不属于单个模型）；留空则用接口默认值

              
              
              
              
              
              
            


            

              
配置 MCP 服务器：stdio 类型填 命令+参数+环境变量；远程类型（sse/http）填 URL。保存后生效，可在 AI 问答中勾选使用

              
MCP 服务器

              
每个服务器默认收起，点标题行展开可查看其配置（只读 JSON）与连通性测试；改配置点行内「编辑」，新增点右上「添加」

              

            


            

              

                技能 Skills
                
                
                
              

              
以目录方式管理技能（含 SKILL.md）。点击卡片启用/停用，可在 AI 问答中选择使用；支持粘贴 npx skills add 命令 / skills.sh / GitHub 仓库链接在线安装

              

            

            

              
              

                
                
              

              
改动后点「应用」生效（需重启应用）；留空应用则恢复默认根目录。此项不自动保存，避免误改导致数据位置变动

              
              

                
                
              

              
点「应用」将整个数据库迁移到新路径并立即生效；留空应用则恢复默认位置。此项不自动保存

            

            

              
              
              
              
              
              
              
              
              
              
              
              
              
              
              
目录引用会在每次列表刷新时实时遍历源目录，因此过大的目录会拖慢界面：超过上限的目录将拒绝添加；已存在的超限引用仅列出前 N 个并在列表顶部告警。调高会相应变慢

超时即终止并回退内置解析，大文档建议 ≥3600，留空用默认值
